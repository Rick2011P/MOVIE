# 🎬 MOVIE — Sistema de Gestión y Consulta de Películas

## Descripción del proyecto

MOVIE es un sistema desarrollado para gestionar y consultar información de películas mediante tecnologías de desarrollo de software y bases de datos.

El proyecto permite realizar operaciones de creación, consulta, actualización y eliminación de registros, utilizando una API REST y una aplicación Java con conexión JDBC a MySQL.

Este proyecto se presenta como evidencia de la actividad **GA7-220501096-AA2-EV01 del SENA**.

## Tecnologías utilizadas

- Java y JDBC
- Node.js y Express
- MySQL
- Postman
- Maven
- Git y GitHub
- Visual Studio Code

## Estructura

**backend/**

Contiene la API REST desarrollada con Node.js y Express, con módulos para autenticación, usuarios, películas y favoritos.

**java-jdbc/MOVIE/**

Contiene la aplicación Java que permite gestionar películas desde un menú de consola mediante JDBC.

## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Administración de películas.
- Consulta y actualización de usuarios.
- Gestión de películas favoritas.
- Control de acceso mediante roles.
- Operaciones CRUD de películas con Java JDBC.
- Persistencia de información en MySQL.

## Pruebas

Se realizaron pruebas funcionales utilizando Postman para comprobar las solicitudes HTTP de la API REST.

También se ejecutaron pruebas de creación, consulta, actualización y eliminación de películas mediante la aplicación Java JDBC.
